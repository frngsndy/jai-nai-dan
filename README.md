# ใจในด่าน

เกมเว็บภาษาไทยขนาดเล็กสำหรับสำรวจรูปแบบการตอบสนองของตัวเองผ่านสถานการณ์สมมติ ในหนึ่งรอบเกมจะสุ่ม 5 สถานการณ์จากคลัง 15 ข้อ ในบริบทชีวิตประจำวันที่หลากหลาย โดยไม่ซ้ำกันในรอบเดียว แต่ละสถานการณ์มีตัวเลือก 3 ทาง คำตอบจะสะสมคะแนนแนวโน้มและพาไปสู่การ์ดบุคลิก 1 ใน 5 ใบ

## วิธีเล่น

เปิด `index.html` ในเบราว์เซอร์ หรือเสิร์ฟโฟลเดอร์นี้ด้วย static web server การ์ดผลลัพธ์พลิกได้ด้วยการคลิก/แตะ และสามารถคัดลอกชื่อการ์ดกับคำอธิบายสั้น ๆ ไปแชร์ได้

## เพิ่มสถานการณ์

เพิ่ม object ใน `scenarios` ภายใน `game.js` โดยใส่ `world`, `icon`, `prompt`, `context`, ตัวเลือกสามข้อความ และ `scores` สามชุด คะแนนใช้แนวโน้ม `warmth`, `clarity`, `calm`, `wonder`, `steadiness` เพิ่มสถานการณ์แล้วระบบจะสุ่มรวมกับข้อเดิมโดยอัตโนมัติ

## หมายเหตุ

เกมนี้มีไว้ชวนทบทวนตัวเอง ไม่ใช่เครื่องมือวินิจฉัยหรือประเมินทางการแพทย์ ฟอนต์ IBM Plex Sans Thai และ IBM Plex Mono โหลดจาก Google Fonts; หากออฟไลน์จะใช้ฟอนต์สำรองของระบบ
